ApprovalLens 0.4.1 is a focused release extraction with shared core logic, hosted advisory MCP, native Cursor guard and extension.

The VSIX is the presentation component. Native interception also requires the local companion and project hooks; see the native setup guide. Hosted MCP does not intercept local tools and the public sample is rules-only unless LIVE credentials and durable spending admission are configured.

This release preserves explicit unknown results, protected-field checks, one-time human review and fail-closed native behavior. macOS/Linux and Node 24 are required for the companion. See README and SECURITY.md for coverage limits. The package is a preview, not a sandbox or universal prompt-injection defense.

0.4.1 improves marketplace setup/privacy documentation and makes extension packaging follow the manifest version. Review logic is unchanged from the 0.4.0 extraction.
