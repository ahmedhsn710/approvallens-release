# ApprovalLens 0.7.3 — readable reviews and scrollable confirmations

All detailed confirmations now share a scrollable layout with a separate action bar, including rule suggestions, Apply rules and hosted-review setup. Native approval reviews and action details organize request information, evidence, model findings and uncertainties into readable sections instead of raw JSON. Closing a pending approval review still denies the request; approval validation is unchanged.

The judge guide now includes the complete installation-to-hosted-review sequence, rule suggestions, explicit policy activation and a sample native tool request.
